# GenLayer Intro

Repositori pengantar tentang GenLayer — infrastruktur kepercayaan untuk ekonomi berbasis kecerdasan buatan.

## Apa itu GenLayer?
GenLayer adalah blockchain AI-native yang memungkinkan kontrak cerdas memahami bahasa alami, mengambil data langsung dari internet, dan menyelesaikan perselisihan melalui sistem konsensus **Demokrasi Optimis**.

## Fitur Utama
- ✅ Kontrak cerdas ditulis dengan Python
- ✅ Memahami bahasa manusia, bukan hanya kode
- ✅ Terhubung ke data dunia nyata secara langsung
- ✅ Sistem validator seperti juri yang adil & transparan
